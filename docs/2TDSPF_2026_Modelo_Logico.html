Dependências e compatibilidade

Veterinário e serviço são entidades próprias, com FKs reais no atendimento. Os campos textuais veterinario e tipo_consulta continuam presentes por compatibilidade com o Java existente. O trigger valida o catálogo e impede uma associação contraditória. Essa redundância controlada está explicitada no modelo físico.
